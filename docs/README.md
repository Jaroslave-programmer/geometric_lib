# \## Geometric Lib

# 

# \## Общее описание

# 

# Geometric Lib — библиотека на Python для вычисления площадей и периметров геометрических фигур.

# 

# В проект входят функции для следующих фигур:

# 

# \- круг;

# \- квадрат;

# \- прямоугольник;

# \- треугольник.

# 

# \## Функции круга

# 

# area(a)

# 

# Вычисляет площадь круга по радиусу.

# 

# perimeter(a)

# Вычисляет длину окружности по радиусу.

# 

# \## Функции квадрата

# area(a)

# Вычисляет площадь квадрата по длине стороны.

# 

# perimeter(a)

# Вычисляет периметр квадрата.

# 

# \## Функции прямоугольника

# area(a, b)

# Вычисляет площадь прямоугольника.

# 

# perimeter(a, b)

# Вычисляет периметр прямоугольника.

# 

# \## Функции треугольника

# area(a, h)

# Вычисляет площадь треугольника по основанию и высоте.

# 

# perimeter(a, b, c)

# Вычисляет периметр треугольника по трём сторонам.

#
