# Geometric Lib

## Общее описание

Geometric Lib — библиотека на Python для вычисления площадей и периметров геометрических фигур.

В проект входят функции для следующих фигур:

- `круг`
- `квадрат`;
- `прямоугольник`
- `треугольник`

## Функции круга

```python
import math


def area(r):
''' 
    вычисляет площадь окружности
    пример: area(5): 78,5
'''
    return math.pi * r * r


def perimeter(r):
''' 
    вычисляет длину окружности
    пример: perimetr(5): 31,4 
'''
    return 2 * math.pi * r
```

## Функции квадрата

```python
def area(a):
''' 
    вычисляет площадь квадрата
    пример: area(5): 25 
'''
    return a * a
 
def perimeter(a):
''' 
    вычисляет периметр квадрата
    пример: perimeter(5): 20 
'''
    return 4 * a
```

## Функции прямоугольника

```python
def area(a, b):
''' 
    Вычисляет площадь прямоугольника.
    Пример: area(3, 5): 15 
'''
    return a * b



def perimeter(a, b):
''' 
    Вычисляет периметр прямоугольника.
    Пример: perimeter(3, 5): 16 
'''
    return 2 * (a + b)
```

## Функции треугольника

```python
def area(a, h):
''' 
    Вычисляет площадь треугольника по основанию и высоте.
    Пример: area(6, 4): 12.0 
'''
    return a * h / 2



def perimeter(a, b, c):
'''
    Вычисляет периметр треугольника.
    Пример: perimeter(3, 4, 5): 12 
'''
    return a + b + c
```
